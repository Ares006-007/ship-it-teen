# Design System

## Typography
- **Headings/Titles:** Sora (Bold)
- **Body:** Poppins (Regular)

## Colors (use exactly)
- **Blue:** `#2563FF` — primary actions, links, focus states
- **Red:** `#FF3B30` — accents, highlights, alerts
- **Yellow:** `#FACC15` — highlights, hover glows, badges
- **Green:** `#10B981` — success states, secondary accents
- **Purple:** `#A855F7` — secondary accents, gradients
- **Black:** `#111111` — primary text, dark UI elements
- **Background:** `#FFFFFF` — predominately white, airy

## Grid System
- 12-column grid.
- Subtle background grid texture (thin light-gray 1px lines, ~24–32px cell size) behind key sections.

## Motifs
- Rocket
- Sparkle/star bursts
- Curved rainbow trail (blue/red/yellow)
- `</>` code glyph
- Swoosh/arrow
- Planet/orbit

## Motion & Micro-interactions
- Buttons: Magnetic hover
- Cards: 3D Tilt
- Badges: Bounce on hover
- Reveal: Fade + upward translate (12-24px), staggered children
